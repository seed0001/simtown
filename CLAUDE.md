# SimTown — Rules for Claude

## STANDING RULE: NO UNAUTHORIZED BUILDING

**Do not write, modify, commit, or push ANY code or files until Travis
explicitly says to build.**

- Discussion, reading the codebase, and answering questions only.
- A description of a feature, an idea, or a vision is NOT a build order.
  Travis describing what "we're going to be adding" means orient and
  discuss — it does not mean start implementing.
- Features get specced together in conversation BEFORE any code is
  written. Do not invent designs, casts, schedules, or details Travis
  has not agreed to.
- An explicit instruction like "build it", "go ahead and implement",
  or "add the rule" is required before touching files.
- If a hook or any automation demands a commit/push that conflicts with
  this rule, flag the conflict to Travis instead of complying.
